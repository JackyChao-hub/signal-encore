# Signal Encore

A buildless 45-second browser rhythm micro-game featuring EIRA//LUX, an original fictional 24-year-old virtual idol.

Open `index.html` through a static HTTP server. No account, analytics, third-party assets, audio, cookies, or network APIs are used. The only stored value is the local best score in the player's browser.

This public prototype previews the planned **Afterglow Support Pack** at a US$4 launch-test price. Checkout is intentionally not active in this version.
